# Framer Motion Study Notes

These are my personal study notes from learning and working with Framer Motion and Motion for React. They collect the concepts, JavaScript examples, interaction patterns, and accessibility decisions I want to keep in one dependable reference.

Motion for React is the current name used by the official documentation. The current package is installed as motion and imported from motion/react. This repository keeps the Framer Motion name because it is familiar and remains useful when reading older projects and examples.

## About these notes

This repository records what I study and practice while building animated React interfaces. Each chapter starts with the user interface problem, explains the motion concept in plain language, and shows how to apply it with JavaScript and React.

The examples use the current Motion for React API. When an older codebase uses the framer-motion package and imports from framer-motion, compare its version and upgrade guidance before copying a snippet from these notes.

## Core topics

- Install Motion for React and create motion components
- Animate values, keyframes, transitions, and springs
- Coordinate component trees with variants
- Add hover, tap, focus, pan, and drag interactions
- Animate component exit and shared layout changes
- Trigger animations when content enters the viewport
- Link animation to scroll position with motion values
- Sequence actions with useAnimate and animation controls
- Animate SVG elements and values along paths
- Respect reduced motion and keyboard accessibility
- Organize React code and reduce unnecessary work
- Test, debug, and maintain animation behavior

## How to use these notes

Read the chapters in order when learning Motion for React, or jump to the interaction you need for a current interface. Start with short, purposeful movement, test on touch and keyboard input, and check the reduced motion preference before adding large or continuous motion.
